Sundin mo ito in order:
1. Start the system
1. Extract the latest ZIP.
2. Make sure kasama ang sample_images folder.
3. Double-click run_windows.bat.
4. Hintaying matapos ang installation at lumabas ang Flask server.
5. Open this URL sa browser:
http://127.0.0.1:5000

API health check: Open http://127.0.0.1:5000/api/health

Dapat may JSON response na nagsasabing "ok": true.
